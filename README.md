# Collage

写真コラージュ作成アプリ（Webアプリ版プロトタイプ）。仕様書の全機能（1〜10枚レイアウト自動生成、写真編集、テキスト、Undo/Redo、テンプレート保存、自動保存、JPEG書き出し）を実装しています。ビルド不要・外部サービス不要・完全無料で動作します。

## 動作の仕組み

- 素のHTML / CSS / JavaScript（ES Modules）のみ。フレームワークやビルドツール不使用。
- 写真データは端末内のIndexedDBに保存（サーバーには一切送信されません）。
- 自動保存はlocalStorageに軽量なJSON（写真は参照IDのみ）を保存する方式なので、閉じても次回起動時に続きから再開できます。
- スマホのSafari/Chromeでも、PCのブラウザでも同じコードで動作します（レスポンシブ対応、iPad含む将来のタブレット対応も考慮したレイアウト）。

## ローカルで試す

ブラウザのモジュール読み込み（`<script type="module">`）はセキュリティ上 `file://` から直接開けないブラウザがあるため、簡易サーバー経由で開いてください。

```bash
cd collage-app
python3 -m http.server 5173
# または
npx --yes serve -l 5173 .
```

ブラウザで `http://localhost:5173` を開きます。スマホで確認する場合は、同じWi-Fi内のPCのIPアドレスに置き換えてアクセスしてください（例: `http://192.168.1.10:5173`）。

## 無料での公開・配布方法（おすすめ）

ビルド不要の静的サイトなので、以下のいずれも無料枠内でそのまま公開できます。

1. **GitHub Pages** — GitHubリポジトリにpushして Settings > Pages で有効化するだけ。最も手軽。
2. **Netlify** / **Vercel** / **Cloudflare Pages** — フォルダをドラッグ＆ドロップ、またはGit連携で自動デプロイ。独自ドメインも無料でHTTPS対応。

公開後、iPhone/AndroidのSafari・Chromeから開けば、そのままWebアプリとして使えます。ホーム画面に追加すればアイコンからフルスクリーンで起動する「PWA的」な使い方も可能です（正式なPWA化＝オフライン対応やアイコン設定をご希望なら追加実装できます）。

## ネイティブアプリ（App Store / Google Play）化したい場合

今のコードはそのままで、無料の **Capacitor**（Ionic製、OSS）でiOS/Androidのネイティブラッパーに変換できます。UIロジックは一切変更不要です。ネイティブビルドにはXcode（Mac）/ Android Studioと、実機配布には各ストアの開発者登録（Apple: 年額、Google: 買い切り）が別途必要になります。この環境では実機ビルド・実配布はできないため、その工程はお手元のMac/Windows環境で行っていただく形になります。

## 実装済み機能

- 写真1〜10枚、奇数枚は最終行を横幅いっぱいに配置するレイアウト自動生成
- キャンバス比率8種類（1:1 / 4:5 / 5:4 / 3:4 / 4:3 / 2:3 / 3:2 / 9:16）、作成後も変更可
- 写真: ドラッグで移動（枠内パン）、ピンチで拡大縮小、2本指で回転、スライダー回転（0〜360°）、クイック回転（90/180/270°）、長押し+ドラッグで配置入れ替え
- 写真フレーム（ON/OFF・太さ・色）、キャンバス背景（白/黒/任意カラー）、写真間隔（0〜50px）、角丸（0〜40px）
- テキスト: 複数追加、フォント/サイズ/色/太字/斜体/揃え/回転/不透明度/行間/文字間隔、ドロップシャドウ（色/距離/ぼかし/角度/不透明度）、ドラッグ移動・ピンチ拡縮・回転
- Undo / Redo
- テンプレート保存（複数・名前付き、レイアウト/背景/間隔/角丸/フレーム/テキストデザインを保存）
- 自動保存（IndexedDB + localStorage、再起動後も編集途中から再開）
- JPEG書き出し（高画質固定、長辺2048px）
- 1画面完結のUI（下部シートで各設定をタブ切替、画面遷移なし）

## 既知の制約（プロトタイプゆえの割り切り）

- 写真の「トリミング」は、ドラッグ（パン）とピンチ（拡大）を組み合わせて枠内の見せたい部分を調整する方式です（専用のトリミング枠UIは未実装）。
- ドロップシャドウはテキストの回転と連動します（絶対角度ではなく、テキストに対する相対角度）。
- 大量の高解像度写真（10枚 x 数十MB）を使う場合、端末のブラウザストレージ容量に依存します。
